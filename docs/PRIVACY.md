# Politique de Confidentialité - Mon Eau

Dernière mise à jour : 7 août 2026

L'application **Mon Eau** est engagée dans la protection de votre vie privée. Cette politique détaille comment nous traitons vos informations.

## 1. Collecte des données
L'application collecte les données suivantes pour calculer vos objectifs d'hydratation :
- **Données de profil** : Nom, âge, poids, sexe, état de grossesse ou d'allaitement.
- **Données d'activité** : Historique des consommations d'eau (millilitres).

## 2. Stockage des données (Local uniquement)
La confidentialité est notre priorité. Toutes les données saisies dans l'application sont stockées exclusivement sur la mémoire de votre appareil (via un stockage local sécurisé). 
**Aucune donnée personnelle ou de santé n'est transmise, vendue ou stockée sur des serveurs externes.**

## 3. Publicité et Liens Tiers
L'application affiche des bannières promotionnelles pour des services tiers (Infomaniak, Indy, iGraal). Le fait de cliquer sur ces liens ouvre votre navigateur web externe. Ces sites tiers disposent de leurs propres politiques de confidentialité que nous vous invitons à consulter.

## 4. Vos droits et contrôle
Puisque vos données sont locales, vous en êtes le seul propriétaire :
- **Modification/Suppression** : Vous pouvez modifier ou supprimer vos profils et historiques directement depuis les menus de l'application.
- **Désinstallation** : La suppression de l'application de votre appareil entraîne la suppression immédiate et définitive de toutes les données enregistrées.
- **Portabilité** : Vous pouvez exporter l'intégralité de vos données au format JSON via la fonction "Sauvegarde" dans les réglages.

## 5. Modifications
Nous nous réservons le droit de mettre à jour cette politique. Toute modification majeure sera signalée par une mise à jour de la date de révision.
